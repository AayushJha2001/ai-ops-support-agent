# Account Security

## Password reset
Use the "Forgot password" link on the sign-in page. The reset link is valid for 30 minutes. If the email does not arrive within 10 minutes, check spam filters and make sure the address matches the account email. Support agents can never see or set your password.

## Two-factor authentication (2FA)
2FA can be enabled under Settings > Security using an authenticator app or a hardware security key. Business and Enterprise admins can enforce 2FA for all members.

## Lost 2FA device
If you lost your 2FA device, use one of your backup codes. Without backup codes, the account owner must open a ticket; identity is verified by the security team, which takes 1 to 2 business days. For security reasons the assistant cannot disable 2FA.

## Suspicious activity
If you notice logins you do not recognise, reset your password immediately, revoke active sessions under Settings > Security > Sessions and contact support. Suspected account compromise is always treated as a high-severity case and escalated to the security team.
